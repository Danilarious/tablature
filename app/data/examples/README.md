# Sanitized Example Fixtures

This directory contains fictional, non-personal example fixtures for BxB Music Notebook.

## Data Privacy Guarantee
All entries in this directory:
- Are strictly fictional demonstrations created for automated testing, API documentation, and import demonstration.
- Contain zero personal compositions, lyrics, audio recordings, or private metadata.
- Serve as safe schemas for developers and contributors working on the open-source codebase.

## Files
- `sanitized-composition.json`: Example composition schema ("Echoes in Open D")
- `sanitized-motif.json`: Example 6-string fingerstyle motif schema ("Cascading Harmonics")
- `sanitized-tuning.json`: Standard Open D tuning specification ("Open D Acoustic")
- `sanitized-export.json`: Example bundle of linked tuning, motif, and composition
