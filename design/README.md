# Design Reference Directory

This directory provides structured access for application design assets:
- `reference/`: Printable PDFs, wireframes, and layout references.
- `illustrator/`: Source Adobe Illustrator vectors (`.ai`).
- `svg/`: Web-ready vector components.

## Pristine Source Material Note
All original design assets remain untouched in their original location at `/assets/`:
- `/assets/SVG/`: Original vector exports.
- `/assets/2x/`: High-resolution PNG renderings.
- `/assets/printed-assets/`: Illustrator master file (`Guitar-Notation-and-tablature_assets.ai`), wireframe PDF, and `ILLUSTRATOR-BUILD-BRIEF.md`.

Per project governance, no original assets in `/assets/` have been moved, renamed, or altered. Proposed moves will be documented and confirmed before moving originals.
